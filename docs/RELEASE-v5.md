# 文件传送 V5 — 共享目录与二维码刷新

建议标签：`v5.0.0`。首次公开发布建议标记为预发布，待更多设备验证后再发布稳定版。

## 新增

- 电脑设置多个只读共享目录，手机浏览器逐层浏览。
- 常见图片预览、兼容音视频按需播放，支持视频进度跳转。
- 共享目录配置保存与停止共享。
- 多部手机分别连接同一电脑进行浏览、下载或播放。
- “刷新二维码 / 访问码”按钮，无需重启即可生成新码并清除来访连接。

## 保留

手机电脑互传、电脑设备发现、多文件与文件夹传输、断点续传、可选加密、SHA256 校验及网络重试。

## 下载与使用

下载 `文件传送V5.exe`，在 Windows 电脑上打开。手机连接同一路由器，扫码并输入电脑显示的访问码。完整说明见附件 `V5使用说明.md`。

## 限制与验证

- 手机浏览走局域网 HTTP，不是 HTTPS；勿开放到公网。
- 不支持手机脱离电脑直传，不提供自动视频转码。
- 默认单文件上传上限 512 MiB。
- 本版已在 Windows 10、Python 3.9.13 环境打包；其他环境未验证。
- 本次整理未运行自动测试或浏览器验证，已有个人使用反馈不代表广泛设备兼容验证。
