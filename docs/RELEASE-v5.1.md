# 文件传送 V5.1 — 文字与链接速传

## 新增功能

- 电脑与手机双向传送文字或链接。
- 始终只保留最新一条内容，新内容覆盖旧内容，不做聊天记录。
- 手机可一键复制；完整内容为 HTTP/HTTPS 链接时可主动打开。
- 多部已连接手机共享同一条最新内容。
- 文字仅存于程序内存，关闭或重启程序后清空。
- 单条文字上限 20,000 个字符。

## 体验说明

- 安卓 Chrome 首次打开系统文件选择器时，可能因 Android 文件管理器冷启动等待约 5～10 秒；手机页面现已加入提示，之后再次打开通常会更快。
- 刷新二维码和访问码不会清空最新文字，但手机需要使用新访问码重新连接。

## 安全与限制

- 文字接口沿用访问码和连接状态验证。
- 收到的内容按纯文本显示，不执行 HTML。
- 只允许用户主动打开 HTTP/HTTPS 链接，不自动跳转。
- 仅适用于可信局域网，手机访问仍为 HTTP，请勿开放到公网。
